# DVLA Coding Exercise — Java

## Overview

This project implements an in-memory vehicle registration registry.

It supports:
- Returning the total number of registrations.
- Finding the vehicle ID associated with a registration number.

## Requirements

- Java JDK installed.

## How to run

Open Command Prompt in the folder containing `Main.java`.

Compile the program:

```bash
javac Main.java
```

Run the program:

```bash
java Main
```

## Example data

- AB01 CDE — 2001 — Vehicle ID 12345
- FG02 HJK — 2002 — Vehicle ID 67890
- L33T H4X0R — 2022 — no vehicle ID assigned
